# Flashcards 

This program is written in C++ and for QT. 

Dependencies:

```
GCC 
QT 6.11

```

To Compile:

```
    git clone https://git.cardinalsystem.net/david/custom-flashcards.git
    cd custom-flashcards/
    cmake -B build -S .
    cmake --build build 
    
```

Run the Flashcards binary inside build/ to run the program.
